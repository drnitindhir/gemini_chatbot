EDU Revolution Gemini Streamlit App

1. Open .streamlit/secrets.toml
2. Replace PASTE_YOUR_GEMINI_API_KEY_HERE with your Gemini API key.
3. Install packages:
   pip install -r requirements.txt
4. Run the app:
   streamlit run app.py

IMPORTANT:
Do not upload .streamlit/secrets.toml to GitHub after adding your real API key.
For Streamlit Community Cloud, add GEMINI_API_KEY in the app's Secrets settings instead.
